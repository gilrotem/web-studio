**נושא:** מחקר טכנולוגי, השוואת מודלים, אופטימיזציית עלויות והרחבת מערכת ייצור וידאו מבוססת AI.

# **1\. רקע ומטרת המחקר**

הפרויקט עוסק ביצירת סרטוני וידאו מקצועיים בהשראת טרנדים עכשוויים ברשתות החברתיות, ובעיקר Instagram Reels.

מדובר בסרטונים המציגים אנימציות מורכבות, תלת־ממד, מוצרים שמתפרקים ומתחברים, תהליכי ייצור, הדמיות אדריכליות, אנימציות המופעלות באמצעות גלילה ועיצוב אתרים אינטראקטיביים.

**דוגמאות מרכזיות:**

* מכונת קפה שמתפרקת לרכיביה, פולי קפה נטחנים וקפה נמזג לכוס.  
* מוצר מזון גורמה המוצג באמצעות תנועות מצלמה, נוזלים, חלקיקים ואפקטים קולנועיים.  
* בניין שנבנה בשלבים, מהיסודות ועד להשלמת החזית.  
* מערכות טכנולוגיות או מכניות המתפרקות לשכבות ומורכבות מחדש.  
* אתרים אינטראקטיביים שבהם גלילת העמוד מפעילה אנימציות תלת־ממדיות.  
* סרטונים המציגים חוויות משתמש, ממשקים אינטראקטיביים ועיצובי אתרים מתקדמים.

## **המערכת הקיימת**

כבר נבנתה תשתית באמצעות Claude Code ו־Skills המפעילים מודלים ליצירת וידאו דרך ה־API של FAL.ai.

המערכת הגיעה לתוצאות מקצועיות, אך נותרו ליטושים ושיפורים.

**הבעיה המרכזית:** עלויות יצירת הווידאו גבוהות יחסית. חלק מהיצירות עולות כמה דולרים, וניסויים חוזרים הביאו להוצאה מצטברת של יותר מ־20 דולר.

## **מטרות הפיתוח**

1. להוזיל משמעותית את עלויות ייצור הווידאו.  
2. לשמור על איכות מסחרית גבוהה, ואף לשפר אותה.  
3. לשלב מודלים סיניים מתקדמים.  
4. לבדוק פלטפורמות API חלופיות לצד FAL.ai.  
5. לשדרג את מערך ה־Skills ב־Claude Code.  
6. להוסיף כלים ליצירת אנימציות באמצעות קוד.  
7. לבנות מערכת היברידית המשלבת Generative AI עם Motion Design מתוכנת.  
8. לאפשר הפקת סרטונים במגוון סגנונות באמצעות תשתית אחת.  
9. ליצור מדידה מסודרת של איכות, הצלחה ועלות לכל יצירה.  
10. לאפשר בעתיד הרחבה לייצור סדרתי ואוטומטי.

* מחירים עשויים להשתנות.

**נוסחת המדידה:**

Cost per Approved Clip \= Total Generation Cost / Number of Approved Clips

מודל זול הדורש ניסיונות רבים עלול להתגלות כיקר יותר ממודל יקר שמצליח מהר.

כתובת: [https\://fal.ai](https://fal.ai/)

## **Runware**

חלופת API שבה נמצאו מחירים אטרקטיביים בחלק מהמודלים.

לדוגמה, במחקר נמצא תמחור של כ־$0.2304לשנייהעבורSeedance2.5ב־720p,כלומרכ־$1.15 לחמש שניות, לעומת כ־\$2.31 ב־FAL בתצורה שנבדקה.

יש לוודא שהתצורות זהות, כולל אודיו, אורך, יחס מסך ומאפייני היצירה.

כתובת: [https\://runware.ai](https://runware.ai/)

## **WaveSpeedAI**

פלטפורמה נוספת המציעה גישה למגוון מודלים.

חלק ממחירי הפתיחה נמוכים במיוחד, אך מתייחסים לתצורות מסוימות, לרזולוציות נמוכות או למסלולי Draft.

**מסקנה:** יש להשוות Endpoints זהים ולא להסתמך על מחיר פרסומי מינימלי.

כתובת: [https\://wavespeed.ai](https://wavespeed.ai/)

## **אסטרטגיית Provider Routing**

במקום לקשור את המערכת לספק יחיד, מומלץ להוסיף רכיב Provider Router שמאפשר:

1. זיהוי המודל המתאים למשימה.  
2. קבלת מחיר עדכני.  
3. בחירת ספק API.  
4. אימות זמינות המודל.  
5. שליחת בקשה במבנה המתאים לספק.  
6. רישום עלות ותוצאות.  
7. מעבר לספק אחר לפי צורך ואישור.

המטרה אינה לעבור באופן מיידי מפלטפורמה לפלטפורמה, אלא ליצור אפשרות להשוואה ולשימוש חכם במספר ספקים.

Remotion מאפשר לייצר סרטונים באמצעות React וקוד JavaScript/TypeScript.

**יכולות:**

* אנימציית טקסט.  
* Motion Graphics.  
* יצירת מעברים.  
* יצירת פתיחים וסיומות.  
* חיבור סצנות.  
* יצירת סרטוני מוצר.  
* עבודה עם תמונות, קטעי וידאו וסאונד.

# **9\. טכנולוגיות משלימות ליצירת Motion**

המחקר הוביל למסקנה שחלק מהעבודות לא צריכות להתבצע באמצעות מודל וידאו גנרטיבי.

## **Remotion**

יצירת אנימציות ווידאו באמצעות קוד.

מתאים במיוחד לטקסט, מעברים, פרסומות גרפיות, אנימציות UI ושילוב סצנות.

## **GSAP \+ ScrollTrigger**

ספריית אנימציה לאתרי אינטרנט.

מאפשרת:

* הנעת אלמנטים באמצעות גלילה.  
* הקפאת Sections בזמן גלילה.  
* שליטה ב־Timelines.  
* Scroll Scrubbing.  
* Parallax.  
* מעברים והמחשות אינטראקטיביות.

אתר:  
[https\://gsap.com](https://gsap.com/)

## **Three.js**

ספריית JavaScript לגרפיקה תלת־ממדית בדפדפן.

מתאימה ל:

* הדמיית מוצרים.  
* סיבוב מצלמה סביב אובייקט.  
* פירוק והרכבת רכיבים.  
* הצגת מודלים אדריכליים.  
* שילוב תלת־ממד עם ScrollTrigger.

אתר:  
[https\://threejs.org](https://threejs.org/)

## **Blender**

תוכנת תלת־ממד המשמשת למידול, אנימציה, תאורה ורינדור.

מתאימה במיוחד להדמיות שבהן נדרשת גיאומטריה מדויקת.

דוגמאות:

* בניין שנבנה קומה אחר קומה.  
* הרכבת מערכת סולארית.  
* פירוק מכונה לרכיביה.  
* אנימציות עם אובייקטים תלת־ממדיים מדויקים.

אתר:  
[https\://www\.blender.org](https://www.blender.org/)

## **FFmpeg**

כלי לעיבוד וידאו וסאונד.

שימושים:

* חיבור סרטונים.  
* המרת פורמטים.  
* שינוי רזולוציה.  
* התאמה ל־Reels.  
* טיפול ברצועות אודיו.  
* אופטימיזציה של קובצי וידאו.

## **Playwright**

יכול לשמש להפעלת אתר אינטראקטיבי, ביצוע גלילה ופעולות בדפדפן והקלטת הדגמות.
