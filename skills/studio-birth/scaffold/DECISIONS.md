# <project> — decisions

Append-only. One entry per ruling. The ruling is the Art Director's words, verbatim, in the
language he wrote them; the session writes the rest. An entry is never edited; a change is a new
entry that supersedes it, and the old one gets a status line. An agent's conclusion is recorded
with origin `agent` and stays that way until the Art Director confirms it; silence is not
approval.

Format:

```
## D-nnn — label
Date · Origin (the Art Director / agent, which session, to which question, on which sheet) · Status (standing / superseded by D-mmm)
Ruling: "<verbatim>"
Means: <what the work does with it; what it locks, by file and section; what it does not lock>
Reopen if: <the condition under which this comes back to the Art Director>
Source: <session and date; the path of the sheet or file>
```
